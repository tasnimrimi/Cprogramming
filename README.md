## About

This repository is reserved for small C exercises completed while learning programming fundamentals. It currently acts as a transparent starting point; source-code exercises will be added in future commits.

## Planned Learning Path

- Variables, data types, input, and output
- Conditions and loops
- Functions and scope
- Arrays and strings
- Pointers and memory
- Structures and file handling
- Small algorithms and problem-solving exercises

## Planned Structure

```text
basics/
conditions-and-loops/
functions/
arrays-and-strings/
pointers/
mini-projects/
```

Each exercise will include a short comment or local README explaining the problem, approach, build command, and example result.

## Compile a Future Exercise

With GCC installed:

```powershell
gcc exercise.c -o exercise
.\exercise.exe
```

## Goal

Build a consistent public record of C practice with small, readable commits rather than presenting an empty repository as a completed project.
